# StudySync – Smart Student Productivity Planner

StudySync is a student-focused productivity and study planning web application designed to help students organize their academic schedules, manage deadlines and stay consistent with their studies.

It brings essential study management tools together in one place, making it easier to plan workloads, track progress and stay on top of academic responsibilities.

## ✨ Features

- **Dashboard:** Get an overview of upcoming tasks, pending assignments and study progress.
- **Task Management:** Add, edit and delete academic tasks with priorities and due dates.
- **Study Planner:** Organize daily and weekly study schedules.
- **Exam Countdown:** Keep track of upcoming examinations and important dates.
- **Syllabus Tracker:** Monitor syllabus completion and subject-wise progress.
- **Focus Mode:** Use a Pomodoro-style timer to manage focused study sessions and breaks.
- **Smart Workload Analysis:** Identify pending tasks and days with heavier workloads.
- **Study Insights:** Track productivity and visualize academic progress.
- **Local Storage:** Save tasks, schedules and preferences directly in the browser.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/agrimatiwari/StudySync.git
   ```

2. Open the project folder:

   ```bash
   cd studySync
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in VS Code.

## 💾 Data Storage

StudySync uses browser LocalStorage to store tasks, schedules, study progress and user preferences.

No backend or external database is required.

**Note:** Data is stored locally in the browser and is not automatically synchronized across devices.

## 🎯 Purpose

StudySync aims to make academic planning more organized and manageable by combining essential study management features into a single platform.

Students can plan their work, track progress and develop more consistent study habits without switching between multiple applications.
